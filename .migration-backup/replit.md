# TD-Coins en Replit

Proyecto Android nativo desarrollado completamente en Kotlin con Jetpack Compose.

## Validación

```bash
./gradlew testDebugUnitTest assembleDebug
```

Requiere JDK y Android SDK 35. Replit no ejecuta un emulador Android en la vista previa; para probar la interfaz se debe instalar el APK en un dispositivo/emulador o abrir el proyecto en Android Studio.

APK debug: `app/build/outputs/apk/debug/app-debug.apk`.
